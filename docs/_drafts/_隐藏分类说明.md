# 隐藏分类（`docs/blog/private/`）

放在这个目录下的文章是**隐藏**的：能通过网址打开、链接可以分享，但不会被展示在列表里。
搜索**仍然能搜到**（隐藏只影响列表展示，不影响搜索）。

> 本文件放在 `_drafts/` 里，所以它自己不会被构建、不会上线、也不进搜索。
> 这是使用说明，不是文章。

## 具体行为

| 位置 | 隐藏分类的文章会怎样 |
| --- | --- |
| 分类首页 `/blog/private/` | ✅ **列出该分类下所有文章**（输入这个网址即可查看） |
| 文章本身 `/blog/private/xxx` | ✅ 正常打开，可分享链接 |
| 首页「最近更新」 | ❌ 不出现 |
| 「全部文章」页 | ❌ 不出现 |
| 归档页 | ❌ 不出现 |
| 标签页 | ❌ 不出现（tag 也不会被创建） |
| 侧边栏 | ❌ 不出现（连「隐藏分类」这个入口也不出现） |
| 站内搜索 | ✅ 能搜到 |

## 怎么用

把文章放进 `docs/blog/private/` 就行，frontmatter 和普通文章一样：

```markdown
---
title: 文章标题
date: 2026-09-30
category: 隐藏
tags: [随便写]
---

正文……
```

## 想公开某篇

把文件从 `private/` **移动**到 `docs/blog/tech/`（笔记）或 `docs/blog/life/`（生活随笔），
它会立刻出现在所有列表里：

```powershell
Move-Item docs\blog\private\某篇.md docs\blog\tech\某篇.md
```

## 实现位置（改坏了知道去哪找）

| 文件 | 作用 |
| --- | --- |
| `posts.utils.mjs` | 定义 `HIDDEN_PREFIX` 与 `isHidden()` |
| `posts.data.mjs` | 用 `isHidden()` **排除**隐藏文章 → 首页、全部文章、归档、栏目页都看不到 |
| `hidden.data.mjs` | 用 `isHidden()` **只保留**隐藏文章 → 供 `/blog/private/` 首页列表使用 |
| `tags.data.mjs` | 同样排除隐藏文章 → 标签页不出现 |
| `posts.scan.mjs` 的 `SECTIONS` | 没有登记 `private`，所以侧边栏扫不到 |
| `blog/private/index.md` | 隐藏分类的列表页，读的是 `hidden.data.mjs` |

> 关键点：`toPost()` 本身**不做隐藏过滤**，过滤放在各个 loader 里。
> 否则隐藏分类自己的首页也会取不到数据。

> 搜索是**刻意保留**的。若想连搜索也藏掉，在 `config.mts` 的 `search.options` 里加：
> ```ts
> _render: (src, env, md) =>
>   env.relativePath.startsWith('blog/private/') ? '' : md.render(src, env)
> ```

## 和 `_drafts/` 的区别

| 目录 | 是否构建 | 网址 | 用途 |
| --- | --- | --- | --- |
| `docs/_drafts/` | ❌ 不构建 | 404 | 临时草稿、模板 |
| `docs/blog/private/` | ✅ 构建 | 正常可访问 | 想发布但不展示的文章 |
