考虑从末状态往前做，思考什么样的状态是可以达到的

先找几个必要条件，首先他移动不了太多，$i \le b_i \le 2n-i$，这是第一个条件

然后不能跨数移动，那么考虑从 $b_i$ 到 $b_{i+1}$ 过程，因为每次只能移动一个数，所以 $a_1$ 到 $a_{2i+1}$ 都不能在 $b_i$ 到 $b_{i+1}$ 之间，这是第二个条件。

这显然是必要的，实际上，他也是充分的，考虑构造性证明，如果 $b_i=b_{i+1}$，加一个最大的和最小的，如果 $b_i<b_{i+1}$ 加 $b_{i+1}$ 和一个最大数，大于同理。

所以我们就对着这个等价条件做，第一个条件相当于每次解锁 $i$ 和 $2n-i$，考虑第二个条件，就相当于把一段连续的数设为不可选，实际上，可选的只有最小的一段数和最大的一段数。

设 $f[i][j][k]$ 表示第 $i$ 个位置，最小 $j$ 个数可选，最大 $k$ 个数可选。

转移直接看代码（学的https://www.luogu.com.cn/article/d710tmlq）

f[n][0][0]=1;
for(int i=n-1;i>=1;i--) {
    int dl=(a[i]!=a[i+1]),dr=(a[2*n-i]!=a[2*n-i-1]);
    for(int l=0;l<=al;l++) {
        for(int r=0;r<=al;r++) if(f[i+1][l][r]) {
            (f[i][l+dl][r+dr]+=f[i+1][l][r])%=MOD;
            for(int k=0;k<l+dl;k++) (f[i][k][r+dr+1]+=f[i+1][l][r])%=MOD;
            for(int k=0;k<r+dr;k++) (f[i][l+dl+1][k]+=f[i+1][l][r])%=MOD;
        }
    }
}
